# JEE Command Centre

## Deploy to GitHub Pages
1. Download and unzip this package.
2. In your GitHub repository, upload/replace `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` in the repository root.
3. Commit changes and wait for GitHub Pages deployment.
4. Open your Pages URL and refresh. If installed as a home-screen app, close and reopen it.

## Features
Home; homework Done/Pending; JEE Main and Advanced countdowns (enter dates yourself); PCM chapter checklist; daily Super 50; test score entry; marksheet filename log; mistake book; revision planner; PYQ counters; focus timer; analytics; dark/light mode; JSON backup/restore.

## Limitations
- Data is stored in localStorage on this browser/device only. Export backups regularly. Clearing site data may erase records.
- No direct Allen Digital connection. Never share your Allen password. Enter marks manually. This version logs the uploaded file name only; it does not extract marks from PDFs/images.
- Guruji hands your prompt to ChatGPT in a new tab. It is not an embedded AI model. A secure backend and API setup are needed for embedded AI; never put secret API keys in frontend code.
- Exam dates are blank until you enter dates verified from official announcements.
- Chapter list is a starter checklist. Verify it against the official JEE 2027 syllabus and your coaching coverage.
